# Thermal Studio

## 启动与检查

先运行插件的 `scripts/start.ps1`。启动后访问 `http://127.0.0.1:<端口>/`，再运行 `scripts/health-check.ps1` 查看 API、计算设备和服务日志。服务只监听本机。

## 推荐工作流

1. 在主界面上传 STL 或 STEP，并等待几何质量检查完成。
2. 为每个组件选择材料或填写导热系数、密度、比热和线膨胀系数；需要组件间传热时确认实体接触或启用空气间隙导热。
3. 添加点热源或面热源，明确功率、作用面、开始和结束时间；添加对流、辐射或散热面并检查环境温度。
4. 设置稳态或瞬态、仿真总时长、计算步长和结果保存间隔。播放速度是前端显示帧率，与求解步长分开设置。
5. 使用 Agent 时先选择 `local` 或 `codex` 模式。`codex` 默认使用本机官方 Codex CLI 登录态解析，CLI 不可用时才需要 API 密钥；提交自然语言描述后只生成配置草案。检查材料、受热面、散热面、功率和时间参数，必要时修改；只有用户点击“确认并仿真”后才运行计算。
6. 仿真完成后检查最高、平均、最低温度、能量平衡和警告，再播放三维温度场或选择组件表面热力图。
7. 在结果区域导出 PDF、Markdown、CSV 或完整三维结果 ZIP。PDF 应使用页面提供的导出按钮生成，确认下载文件扩展名为 `.pdf`。

## Agent 提示词模板

“导入当前 STL。整个外表面作为实体传热域；上半部分施加 50 W 面热源，下半部分设置环境温度 25 °C、换热系数 20 W/(m²·K) 的对流散热；启用空气间隙导热和自然对流；使用瞬态求解，总时长 3600 s，计算步长 20 s，保存间隔 20 s，播放 10 帧/秒。请先返回完整配置草案和校验结果，等待我确认或修改，确认后再仿真并生成 PDF 报告。”

## 故障处理

- `Failed to fetch`：运行健康检查，确认端口和 `.runtime/server-error.log`；不要重复提交同一个作业。
- 全部温度等于环境温度：检查热源功率是否大于零、受热面是否有选中三角面、仿真时间是否大于零。
- 组件温度不互相影响：确认组件实体接触共享节点，或启用空气间隙并设置有效间隙；报告中的“有效耦合面积”不能为零。
- Codex 请求失败：确认 `OPENAI_API_KEY` 已在当前用户环境变量中设置。HTTP 429 表示账户 API 额度不足，HTTP 403 表示上游只允许官方客户端；这两种情况都不是本地仿真器可通过改参数解决的。
